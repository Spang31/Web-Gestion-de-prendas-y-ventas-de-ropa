# Gestión de Inventario

Este proyecto es una página web para mostrar un catálogo de ropa, con secciones separadas para hombre y mujer.

## Archivos principales

- `index.html` - Página principal
- `hombre.html` - Catálogo de ropa para hombre
- `mujer.html` - Catálogo de ropa para mujer
- `privacidad.html` - Política de privacidad

## Carpetas

- `css/` - Estilos de la página
- `js/` - Archivos JavaScript
- `img/` - Imágenes
- `lookbook/` - Fotos del catálogo

## Cómo usar

Simplemente abre `index.html` en tu navegador para ver la página.
